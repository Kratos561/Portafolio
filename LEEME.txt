2. AÑADIR PROYECTOS (SIN CÓDIGO) — PANEL DEL PROPIETARIO
----------------------------------------------------------------
Dirección: <web>/admin.html  (no está enlazada en ninguna página y
lleva noindex; solo el dueño la conoce).
  1. Entrar con un token de GitHub "fine-grained":
     Repository access → Only select repositories → Portafolio
     Permissions → Contents: Read and write
     El panel solo deja entrar a la cuenta Kratos561.
  2. "Nuevo proyecto": Arte 3D (sube una imagen: se convierte a WebP y
     se reduce a 2400 px) o Video (pega el enlace de YouTube: el título
     se rellena solo). Campos: título, descripción, categoría, año,
     herramientas, etiquetas, enlace externo, "Destacado".
  3. Ordenar con las flechas, destacar con la estrella, editar o borrar.
  4. "Publicar en la web": hace UN commit en main con la imagen y
     data/projects.json. Se ve AL INSTANTE: la web lee los proyectos de
     la API de GitHub y, mientras GitHub Pages copia la imagen nueva
     (≈1 min), la carga desde raw.githubusercontent.com.
     Límite de la API sin sesión: 60 consultas/hora por visitante (las
     revalidaciones 304 no cuentan); si se agota, la web usa la copia
     data/projects.json de GitHub Pages, que llega en ≈1 min.
La web pública no muestra ningún enlace ni botón al panel: se entra
escribiendo admin.html en la barra de direcciones.
Seguridad: el token nunca está en el código; vive solo en el navegador
del dueño. Si se pierde o filtra, revocarlo en GitHub y crear otro.

4. PRESENTACIÓN DE PROYECTOS (assets/projects.js)
----------------------------------------------------------------
- Distribución automática para cualquier cantidad: 1 → ancho;
  2 → dos mitades; 3+ → el primero ancho y el resto en pares; si sobra
  uno, el último también va ancho. Se recalcula al filtrar.
- Filtros por categoría: aparecen solos si hay 2 o más categorías.
- Tarjeta: miniatura (YouTube en alta cuando existe), categoría, número,
  título, descripción (3 líneas), etiquetas.
- Visor (<dialog>): imagen completa o video con autoplay; anterior /
  siguiente, flechas del teclado, Esc, deslizar en móvil, enlace a
  ArtStation/YouTube. Enlace directo: 3d.html#ver=vintage-optics.
- Datos rotos (sin título o sin imagen/ID) se ignoran; ids destacados
  que ya no existen también. Si el JSON no carga, se muestra un aviso
  con enlaces a YouTube y ArtStation.

6. LA SERPIENTE ([data-snake] en el h1 .poster)
----------------------------------------------------------------
Dos SVG (detrás y delante de las letras) redibujados en cada frame:
  - Cuerpo con volumen: borde oscuro, cuerpo con escamas finas,
    rombos dorsales que siguen la curva y brillo en el lomo.
  - Cabeza de víbora (mandíbula ancha y cuello), ojos con brillo,
    fosas nasales y lengua bífida con doble chasquido cada ~3,4 s.
  - La cabeza sigue al cursor en vertical (solo ratón).
  - Entrelazado alterno: por detrás de la letra anterior a la alta,
    por delante del trazo izquierdo de la alta, por detrás del derecho
    y por detrás de la letra de la cola.
  - Entra reptando y ondula; se pausa fuera de pantalla; con
    prefers-reduced-motion queda quieta.
  - data-snake-head / data-snake-tail: índice de letra (sin espacios).
  - Tamaño: portada 92vw / 4.36; subpáginas --poster-w (VIDEOS 2.55,
    ARTE 3D 2.98). Si cambias la palabra, mide offsetWidth / font-size.
