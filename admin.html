Acceso

Solo para el propietario. Entra con un token de GitHub con permiso de escritura en el repositorio Kratos561/Portafolio.

¿Cómo creo el token?
  1. Abre GitHub → Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories → Portafolio.
  3. En Permissions → Repository permissions pon Contents: Read and write.
  4. Genera el token, cópialo y pégalo aquí. Nunca lo compartas.
